# AI & Machine Learning Engineer Portfolio

A premium, production-ready developer portfolio designed specifically for AI Researchers, Machine Learning Engineers, and Data Scientists. Built with extreme performance and elegant UI/UX in mind, targeting top-tier AI companies (OpenAI, DeepMind, Anthropic).

## 🚀 Overview

This portfolio is a **100% static website** requiring **zero build tools**. It relies purely on semantic HTML5, modern CSS3 (with variables and glassmorphism), and Vanilla JavaScript to deliver a lightweight, lightning-fast experience without the overhead of React or Next.js.

## ✨ Features

- **Zero Configuration Setup:** Clone and open `index.html`. No `npm install`, no build step.
- **Cyber AI / SaaS Aesthetic:** Modern dark theme utilizing glassmorphism, subtle glowing gradients, and CSS variables.
- **Advanced Interactive Canvas:**
  - Neural network particle background in the Hero section.
  - Interactive "Skills Constellation" physics node graph.
- **High-Performance Animations:** Custom Vanilla JS scroll reveals, 3D mouse tilt effects, and animated metric counters using `IntersectionObserver` and `requestAnimationFrame`.
- **Fully Responsive:** Mobile-first design perfectly adapted for all devices via clean media queries.
- **SEO & Accessibility Ready:** Semantic HTML, ARIA labels, semantic meta tags, structured Schema.org JSON-LD data, and `prefers-reduced-motion` compliance.
